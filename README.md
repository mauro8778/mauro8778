## 🚀 Proyectos Destacados

### 🐾 [Los 5 Mosqueteros — Pet Rescue & AI Care](https://github.com/mauro8778/los-5-mosqueteros)
Plataforma integral de rescate animal y adopción responsable con **evaluación automática de compatibilidad adoptante-mascota impulsada por Google Gemini AI**, gestión de turnos veterinarios, chat en tiempo real y tienda solidaria con checkout de Mercado Pago.
- **Stack:** NestJS, TypeScript, PostgreSQL, Prisma, Redis, Google Gemini 2.0 Flash, Socket.io, Mercado Pago, Docker, Swagger.
- **Puntos clave:** Scoring etológico inteligente, arquitectura modular por dominios, flujo transaccional con reserva de inventario y WebSocket Gateway bidireccional.

### 🏥 [TurnoClínica Enterprise API](https://github.com/mauro8778/TurnoClinica-Back)
Plataforma backend de alto rendimiento para gestión médica hospitalaria, preparada para alta concurrencia con triaje automatizado con Inteligencia Artificial.
- **Stack:** Node.js, Express, TypeScript, PostgreSQL, Redis, BullMQ, Google Gemini AI, Docker, Swagger.
- **Puntos clave:** Bloqueos distribuidos en Redis contra race conditions (anti-doble reserva de turnos), colas asíncronas con BullMQ para procesamiento en background, y motor de triaje clínico inteligente bajo el estándar médico ESI.

### 🌙 [Guardia Nocturna — Fullstack Tutoring & Academic Shifts](https://github.com/mauro8778/guardia-nocturna)
Monorepo fullstack empresarial para gestión y reserva de clases particulares y guardias académicas en tiempo real.
- **Stack:** NestJS, TypeScript, React 18, Vite, Prisma, PostgreSQL, Supabase, Socket.io, Google Gemini AI, Docker.
- **Puntos clave:** **Modo Fantasma (Ghost Mode)** para auditoría de SuperAdmin, Asistente Docente con exportación directa de planificaciones a Word (.docx), sincronización de turnos por WebSockets y cálculo de cobertura a domicilio.

### 🎯 [LeadFinder Local — B2B Automated Prospecting Engine](https://github.com/mauro8778/leadfinder-local)
Motor SaaS para agencias de prospección y cierre comercial en frío de negocios locales sin presencia digital.
- **Stack:** Next.js 16 (App Router), React 19, TypeScript, SQLite / LibSQL, Tailwind CSS v4, Docker, OpenStreetMap (Overpass + Nominatim).
- **Puntos clave:** Scraping geoespacial de comercios sin coste de Google Maps, clasificador automático de madurez web, generador de páginas demo interactivas en vivo y canal directo de WhatsApp.

### 🛒 [E-Commerce API](https://github.com/mauro8778/E-commerce)
Backend para plataformas de comercio electrónico preparado para transacciones y control de stock.
- **Stack:** NestJS, TypeScript, PostgreSQL, JWT, Docker.
- **Puntos clave:** Autenticación segura, carrito de compras transaccional y estructura escalable.
